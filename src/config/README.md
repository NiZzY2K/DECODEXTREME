# Content configuration

Update content here without editing page layouts:

| File | Purpose |
| --- | --- |
| `event.js` | Event details, contact email, IEEEXtreme URL, session dates and descriptions |
| `registration.js` | Event and hackathon registration URLs (HTTPS), plus the event registration closed switch |
| `team.js` | Departments, members, portrait paths and LinkedIn links |
| `navigations.js` | Shared header, mobile drawer and footer links |
| `content.js` | Frequently asked questions, learning principles and event highlights |

Keep session timestamps in ISO format with `+05:30`. Leave unpublished registration URLs empty; the UI shows an unavailable state. Add only confirmed team profiles, using unique member IDs and images in `public/images/team/`.
